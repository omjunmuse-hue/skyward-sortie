Skyward Sortie: an original 3D flight game over the island of Kestrel Bay, written in dependency-free JavaScript on a hand-rolled canvas renderer. Take off from the coastal strip, fly all six target rings in order — minding throttle, the stall, fuel and hull — then land back on the runway to complete the sortie. Chase and cockpit views, a full instrument HUD (airspeed, altitude, heading, artificial horizon), procedural engine and wind audio, keyboard and mouse controls.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts — then open out/game/index.html in a browser (or serve game/ statically) and press any key to take off
```
